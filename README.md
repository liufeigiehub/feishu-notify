# Feishu Duty Notification (飞书自动值班提醒机器人)

这是一个基于 **GitHub Actions** 和 **Shell 脚本** 驱动的纯云端自动化排班提醒机器人。
它无需占用本地服务器资源，通过配置触发器自动在每周周末和所有法定节假日前夕，将值班安排推送至飞书群聊。

---

## 🤖 工作原理

本系统通过 `.github/workflows/feishu_notify.yml` 进行统一管理。其核心逻辑包含：

1. **多维度触发 (Cron)**：
   - 默认在每周的周五、周六、周日 UTC `02:54` (北京时间 `10:54`) 自动唤醒。
   - 针对落在工作日 (周一至周四) 的法定节假日，单独配置了额外唤醒规则，确保假期不漏发。
2. **智能年份切换**：
   - 脚本内置动态判断逻辑，根据当前服务器年份（`2026` 或 `2027`）自动读取对应的排班表与节假日数据字典，实现平滑过渡。
3. **优先级拦截机制**：
   - **调休补班日**：匹配到 `MAKEUP_WORKDAYS` 字典时，不安排值班，自动输出“无需值班”。
   - **法定节假日**：匹配到 `HOLIDAYS` 字典时，节假日当天以及放假前一天会合并输出 **整个假期内的所有排班**。
   - **常规周末**：排除上述情况后，按 `SCHEDULE` 字典正常输出周六/周日的排班。

## 🛠️ 后续如何维护与修改？

如果人员发生变动，或国家发布了最新的放假安排，你只需要修改 `feishu_notify.yml` 文件中的对应部分。

### 1. 修改/增加法定节假日
如果在未来年份需要更新法定节假日，请找到对应的年份字典（如 `HOLIDAYS_2027`）：
```bash
declare -A HOLIDAYS_2027=(
    ["01-01"]="元旦"
    ["05-01"]="劳动节"
    # 格式为: ["MM-DD"]="节日名称"
)
```
**注意：** 增加日期后，必须同步将这些日期添加到 `HOLIDAYS_STR`（序列化字符串）中，以供发送步骤读取。

### 2. 修改“调休补班日” (非常重要！)
每年年底，国务院会发布下一年的法定节假日放假调休安排。你需要根据通知，将**因为放假而需要周末上班的日期**填入补班字典中：
```bash
MAKEUP_WORKDAYS=(
    ["04-25"]="五一调休补班"
    ["05-08"]="五一调休补班"
)
```
填入该字典的周末将**不会安排值班**，机器人会自动向群里发送“无需值班”的提示，防止乱轴。

### 3. 修改人员轮流排班表
如果团队人员有进出，需要调整排班，请在 `SCHEDULE` 字典中修改对应日期的名字：
```bash
SCHEDULE=(
    ["01-09"]="张三、李四"
    ["01-10"]="王五、赵六"
)
```
**注意：**
- `SCHEDULE` 只排常规的周六和周日。
- 节假日的值班人员是**单独配置**在 `HOLIDAY_DUTY_STR`（比如 `HOLIDAY_DUTY_STR_2027`）这个长字符串里的，格式为 `日期:人员|日期:人员`。如果节假日换人，去这个长字符串里改。

### 4. 补充新增节假日的 Cron 触发器
如果你在字典里增加了原本属于工作日 (周一到周四) 的放假日期（比如中秋节正好在周三），你需要到文件最顶部的 `on: schedule:` 下方，加一行 Cron 规则，否则 GitHub 无法在那天醒来：
```yaml
  schedule:
    # 假设新增 9月15日(周三) 为中秋节
    - cron: '54 2 15 9 *'  
```

## 🛡️ 环境密钥配置
本项目依赖飞书机器人 Webhook URL。
请勿将完整的 Webhook 地址硬编码在代码中。需要在本 GitHub 仓库的 **Settings -> Secrets and variables -> Actions** 中，配置名为 `FEISHU_WEBHOOK_URL` 的 Secret 变量，脚本在运行时会自动读取该变量发送请求。
